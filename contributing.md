## 🎛️ Presets Beat Manual Tuning

Every value is adjustable. The reason presets exist is that most people should
not adjust them.

**What a preset stores**

| **Group** | **Contents** |
| --- | --- |
| Visual | which layers, colours, ranges |
| Assist | targeting, motion, gating |
| Cosmetic | active appearance set |
| Utility | keybinds, hotkeys |
| Identity | reset options, where applicable |

**The four that ship**

| **Preset** | **Character** |
| --- | --- |
| Minimal | overlay only |
| Standard | overlay plus assist |
| Full | everything except cosmetics |
| Clean | everything off |

**Why "Clean" is the most useful one**

A preset with every module disabled lets you play a completely ordinary session
without uninstalling anything. It also gives you an immediate baseline: if
something feels wrong, switch to Clean and see whether it persists. Half of all
"the game is stuttering" reports are a module that was left on.

**Custom profiles**

Save as many as you want under your own names. Each is a separate file, so they
back up and move between machines independently.

**Editing discipline**

Tune on a copy. Copy the tuned version over the profile you actually play with
only once it has proven itself. Editing the live profile mid-session is how a
good setup quietly degrades over a month.

**Order of operations**

1. Close the game and its launcher completely.
2. Run the loader as administrator.
3. Open the **Spoofer** tab and press **Spoof**.
4. **Reboot** — volume serial and SMBIOS are read at boot.
5. Create a fresh account and log in.

**What it does not do**

It does not unban the old account. It gives the machine a new identity so a new
account is not linked to the old ban.

**Skipping the reboot is the most common mistake** — people report "the spoofer
did nothing" when they simply never restarted.
